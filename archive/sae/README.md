# Archived SAE work

This directory preserves tests and notes for the earlier, optional SAE
training and feature-analysis work. It is not part of the active activation
analysis package and is intentionally not collected by the default test suite.

The active activation-vector iterator now lives in
`src/activation_analysis/activation_store.py`. The archived tests may require
the old ignored `src/sae/` implementation and are retained only as historical
reference until that work is deliberately revived.
