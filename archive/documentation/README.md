# Documentation archive

This directory preserves earlier planning documents as versioned snapshots.
They are useful for understanding how the project evolved, but they are not
the authority for current implementation decisions.

## Legacy snapshots

- `legacy/PROJECT_ARCHITECTURE_v0.md` — earlier generic architecture proposal.
- `legacy/SCIENTIFIC_PROTOCOL_v0.md` — earlier cross-construct protocol draft.
- `legacy/CHAT_HANDOFF_v0.md` — earlier handoff summary.

The current direction is defined by the root-level documents:

1. `PROJECT_DIRECTION.md` — canonical scientific scope and claims.
2. `readme.md` — human-facing project overview and status.
3. `SCIENTIFIC_PROTOCOL.md` — current experimental protocol.
4. `PROJECT_ARCHITECTURE.md` — current implementation boundary and roadmap.
5. `AGENTS.md` — instructions for coding agents.
6. `agents/` — maintainer handoffs and execution notes; these are operational
   and do not override the root scientific documents.
